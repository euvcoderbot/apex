# macOS HIG audit — every UI element (2026-10-22)

Scope: both views (Session analysis, Car performance), sidebar, toolbar, menus, dialogs, in dark and light appearance, at desktop and phone widths. Measured in the running app (2025 Japanese GP Q, 2026 Melbourne Q, 2026 car performance) with a script that groups every control by family (`data-ui-kind`) and records height, font, weight, radius, fill and shadow.

References are to Apple's Human Interface Guidelines, https://developer.apple.com/design/human-interface-guidelines/ + the page slug in brackets.

## What changed in this pass

1. **One owner per control family.** New final CSS layer `hig-system.css` (`@layer system`, after `window`). Each family is styled once (size, type, radius, fill, hover, pressed, selected, disabled, motion). Earlier layers can still lay controls out, but no longer decide how they look. Before this, a run segment was styled in 10 files (`apple-ui`, `design-system`, `macos-ui`, `macos-window`, `ui-controls`, `workspace-ui`, `polish`…), and the last rule set its hover to `transparent`.
2. **Q1 / Q2 / Q3 run picker fixed.** Hover now shows a fill on unselected segments. Clicking no longer flashes: `replaceUI` patches the existing DOM instead of replacing it, so the card, team logo image, buttons and hover state survive and only a 120 ms colour transition runs. The old `scale(.98)` bounce is gone.
3. **Checkboxes are rounded squares** (were circles — a circle reads as a radio button on macOS).
4. **Single type ramp.** Off-ramp sizes removed (16 px section headers, 11 px badges, 28 px/700 category title, 15 px "Choose laps").
5. **Visible-trace chips are neutral.** The team-coloured border is gone; the colour well alone carries the trace colour.
6. **Run-card names are natural case** ("Max Verstappen", not "Max VERSTAPPEN"), matching the source list.
7. **Speed-trace sector labels never collide** ("SECTOR 2SECTOR 3" became "S2"/"S3", or is omitted when there is no room).
8. Entrance animations no longer replay when a panel re-renders, and Reduce Transparency and Increase Contrast now have explicit fallbacks.

## Size system [buttons] [layout]

macOS has mini, small, regular and large control sizes. This app uses three, scaled +1–2 px for its denser web type:

| Size | Height | Radius | Used by |
|---|---|---|---|
| Large | 32 px | 6–7 px | Source-list rows (drivers, races), category bar tabs |
| Regular | 30 px | 8 px | Push, default (primary), pop-up, field, toggle tile, segmented track, toolbar items, disclosure |
| — thumb | 26 px | 7 px in a 9 px track | Segments inside a regular segmented control |
| Small | 24 px | 6 px | Chart steppers (zoom/pan/reset), reference chip, sort headers |

## Selection and highlight [focus-and-selection]

Unchanged from `docs/selection-and-lists-spec-20261022.md` and now enforced by one layer: rings only for keyboard focus; list rows use filled selection; exclusive choices use the segmented thumb; on/off tiles use the accent fill; team colour never shows state.

## Materials [materials]

Translucency only where content scrolls underneath and the material helps orientation: toolbar, pop-up menus, tooltips, toast. Group boxes, cards and charts stay opaque (legibility of data). With **Reduce Transparency** these become opaque.

## Motion [motion]

| Motion | Duration | Purpose |
|---|---|---|
| Hover, press, selection fill | 120 ms ease | Feedback; colour only, no scaling or bouncing |
| Menu / popover in | 120 ms | Shows where the menu comes from |
| Disclosure reveal, view change | 180–240 ms | Continuity between states |
| Metric bars on category entry | 320 ms (was 460) | Shows the new ranking once, not on every redraw |
| Card moved by a list change | 280 ms FLIP | Keeps track of a moved card |

Removed: entrance animations that replayed on every re-render, the `scale(.98)` selection bounce. **Reduce Motion** disables transitions and animations.

## Accessibility [accessibility]

- Focus ring: 3 px accent, `:focus-visible` only.
- Increase Contrast: control bezels and segmented tracks get a 1 px border.
- Forced colours: selection uses system Highlight.
- Light and dark label colours meet 4.5:1 on panels (tested).

## Follow-ups, resolved in the second pass

1. 🔧 **Duplicate titles on Car performance** [layout]: a card header that repeats the page title ("Braking" under "Braking", "Reliability and results" under "Reliability & results") is hidden, so the chart title leads the card.
2. 🔧 **2025 Kick Sauber (Stake) mark**: transparent black and white "Stake" wordmarks replace the opaque lockup, swapped by appearance like the official 2026 marks.
3. 🔧 **Sliding segmented thumb** [segmented-controls] [motion]: every segmented control and the category bar draw one thumb (`::before` of the group) that slides 200 ms to the chosen segment; the first placement appears in place, Reduce Motion removes the slide, forced colours fall back to Highlight.

## Corner and table corrections after the screenshot review

The circuit-guide info button/popover and corner-envelope/type/method notes are removed. Selected sections show their name and length. Corner measurements now use a native four-column table with consistent numeric alignment, compact driver identity, visible bordered sort buttons, sort-direction feedback and reversible sorting. Narrow panels reduce header chrome while preserving the units; the four columns fit a 287 px phone table without horizontal scrolling. The optional diagnostic has a full-width padded disclosure and retains its open state across re-render/resize.

All performance-table headings keep words intact and use intrinsic header widths. The pit-stop and results summary tables fit the checked 1280 px layout without page overflow. Wide evidence tables retain their own scroll region.

Timing delta uses 5 percentage-point zoom steps, exact continuously scaled plot limits and separately spaced ticks. Fit restores the complete 100% range. Re-rounding zoomed bounds had swallowed small changes. Tests assert the actual plotted limits at 95% and 105%, compression, magnification and Fit; the corner-sort regression verifies both directions with unknown values last.
